Changements pas encore publiés

Tout ce que tu as enregistré avec « Save » et qui n’est pas encore sur le site en ligne.

Comment ça marche

  1. Modifie dans l’onglet « Modifier le contenu », puis clique sur Save (enregistrer).
  2. Vérifie le résultat dans l’onglet « Aperçu du site ».
  3. Publie avec le bouton vert en haut à droite. Le site en ligne est à jour 2 à 3 minutes après.

 

N’oublie pas de cliquer sur Save après chaque modification.
